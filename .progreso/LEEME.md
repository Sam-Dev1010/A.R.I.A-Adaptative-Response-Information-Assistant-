# Progreso de A.R.I.A — Historico de sesiones

Este directorio guarda el progreso diario del proyecto A.R.I.A, sesion por
sesion, para retomarlo de forma limpia cada vez que se trabaje.

Convention: un archivo `SESION_YYYY-MM-DD.md` por dia, con:
- Objetivo de la sesion
- Lo que se hizo (y que funciona)
- Metricas / hallazgos medidos
- Que quedo pendiente
- Primeras tareas para la siguiente sesion (reactivacion)

El archivo `ESTADO.md` siempre refleja el estado actual del proyecto.
