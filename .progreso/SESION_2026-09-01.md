# PROGRESO A.R.I.A — 2026-09-01 (Sesión 2)

## Objetivo
"Adelantar la IA ARIA": validar la vectorización NumPy pendiente, crecer el
corpus del internet, escalar capacidad del modelo y evaluar la calidad de
generación libre del GPT propio.

## Qué se hizo (funciona, todo commiteado)

### 1. Vectorización NumPy validada y commiteada (`db42035`)
- El forward/backward vectorizados (trabajo previo sin commitear) pasan los
  282 tests del proyecto y el modelo sigue aprendiendo (loss baja, acc sube).
- **Velocidad**: ~9.4 s/época (159 secuencias) frente a los ~168 s/época
  originales → **~18x más rápido**. Se acabó el cuello de botella del
  entrenador; "aprender del internet" ya es viable.

### 2. Fix de generación: colapso a `<unk>` (`79e5fea`)
- Hallazgo: en `generate()`, la máscara de tokens de control solo se aplicaba
  si `vocab_mask_size < len(logits)`. En el caso real (máscara == vocab=2048)
  NUNCA se ejecutaba, así que el modelo colapsaba emitiendo `<unk>` (id 1)
  repetido y la respuesta decodificaba vacía.
- Fix: `<unk>`, `<bos>`, `<user>`, `<assistant>` se excluyen SIEMPRE.
- Test de regresión añadido (`test_generate_siempre_excluye_control_con_vocab_completo`).
  283/283 tests OK.

### 3. Corpus del internet crecido y luego CURADO (`0608676`)
- Se bajaron 40 artículos + temas (IA, programación, informática, Colombia).
- Se detectó que el corpus crudo era ruidoso: artículos oscuros (Codominancia,
  Zosterops), duplicados sintéticos (un mismo extracto respondía 3-4 preguntas
  casi iguales) y oraciones truncadas a mitad.
- **Curación**: corpus.json pasó de 63 conv → 9 conv (una sola pregunta útil
  por artículo, extracto completo) y de 13 → 9 textos. Se borró el ruido y la
  redundancia que provocaban generación degenerada/repetitiva.
- `learn_from_web.py` mejorado para el futuro: filtra extractos < 200 chars,
  genera una sola pregunta general + detalles solo con oraciones completas.

### 4. Reentrenado completo con corpus limpio
- `retrain_full.py` → modelo actual (377,472 params) reentrenado con 160 conv
  + 60 textos. loss 5.757, ppl 316.46. Desplegado en `data/aria_gpt` y
  `data/neural`.

## Experimento de capacidad (dato clave para el futuro)
- Modelo actual (64/2/4, 377K): genera `<eos>` al instante o texto repetitivo.
- Modelo escalado (128/4/8, **1,345,792 params**): logra frases reales
  ("Alonso Quijano es el nombre del hidalgo don Quijote...") pero degenera en
  repetición; loss inestable (LR demasiado alta / overfit con corpus pequeño).
- Conclusión: escalar MEJORA la fluidez, pero hace falta (a) corpus de mayor
  calidad aún y (b) entrenar el modelo grande con LR más baja + decay para
  evitar la inestabilidad.
